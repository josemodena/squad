# Squad 0.5.2 — GPT-6.1 Sol defaults

Codex Engineer and Engineering Reviewer assignments now default to `gpt-6.1-sol`.
The PM and architecture roles retain Astra. Claude model assignments are unchanged.
README, setup templates and model-update guidance reflect the new identifier.

Update the plugin and CLI checkout. New assignments use the new default unless
project settings or environment variables explicitly override it. Existing jobs
keep their recorded model. There is no board or runtime migration.

The identifier was verified against official OpenAI documentation and the local
Codex catalogue. This does not constitute a live inference or quality benchmark.
The catalogue advertises a default effort of `low`; explicitly select `medium`
if retaining the previous Sol default is intended. Preserve supported explicit
effort settings; `none` and `minimal` are unsupported by the new model.

See [model updates](https://github.com/josemodena/squad/blob/v0.5.2/docs/guides/model-updates.md).
The full repository validation workflow covers both plugin packages and existing
model-binding protections. This release changes model defaults only; proposed
changes to the Administrator/PM architecture remain a separate discussion.
