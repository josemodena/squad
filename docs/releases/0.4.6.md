# Squad 0.4.6 — model defaults and upgrade checks

Codex now defaults to GPT-6-Luna for Administrator and GPT-6-Sol for Engineer
and Engineering Reviewer. GPT-6-Astra remains the planning and architecture model.
New-project templates match these defaults; explicit project overrides remain intact.

`squad models --check-upgrades` reads Codex's catalogue and reports advertised
replacements, missing models and unfinished jobs. It performs no model inference
and makes no settings, job or session changes. The existing `squad models` output
is unchanged. Catalogue presence does not guarantee access; a failed check never
selects a fallback. Claude automatic discovery is explicitly unsupported.

Claude Code retains `sonnet`, `fable` and `opus` aliases, documented as Sonnet 5,
Fable 5.1 and Opus 5.5 for Anthropic's current defaults. Provider and environment
overrides may differ. Opus 5.5 requires Claude Code 2.1.280 or later.

Before installing, reconcile or checkpoint running work. Pin old models in project
settings if the project must stay on them during rollout. Existing jobs retain
their recorded models. A managed Codex Administrator needs an idle session
rollover before using a new model; user pauses and quota policy remain unchanged.
See the [model update guide](https://github.com/josemodena/squad/blob/v0.4.6/docs/guides/model-updates.md).

Validation includes malformed/unavailable catalogues, timeout handling, custom
model overrides, missing upgrade targets, read-only CLI behaviour and preservation
of a claimed job's model after its role default changes.
