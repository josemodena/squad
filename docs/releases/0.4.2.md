# Squad 0.4.2 — first GitHub release

Squad coordinates a development team inside Codex or Claude Code: planning,
architecture, implementation and independent review, with role-specific models,
GitHub tracking and durable recovery. This is the first tagged GitHub release;
the changelog retains earlier development versions.

## Included

- Six roles with explicit handoffs, native subagent completion, model routing,
  dependencies, checkpointing and review of the exact implementation revision.
- Separate self-contained Codex and Claude Code plugins and a shared Linux CLI.
- Apache-2.0 licensing, contributor guidance and a first-project tutorial.
- A Spec-Driven Development integration guide.
- REST pagination compatible with GitHub CLI 2.46.0; diagnostics now check the
  supported minimum. Earlier installations could fail with `unknown flag: --slurp`.
- Clearer setup-commit, test-artifact and agent prerequisite/quota instructions.
- Automated tested tag releases with source archives and SHA-256 checksums.

## Install or update

Follow [installation](https://github.com/josemodena/squad/blob/v0.4.2/docs/getting-started/installation.md), then the
[first delivery cycle](https://github.com/josemodena/squad/blob/v0.4.2/docs/getting-started/quickstart.md). The complete source
archive contains `install.sh` and `bin/squad`; individual plugin archives contain
only the self-contained plugin. Keep the extracted source directory when using
the CLI installer, because the installed command links to that directory.

Existing settings, runtime records and deliberate pauses remain in place. Updating
Squad does not authorise a paused project to resume. Restart the harness session
after updating plugins so its loaded instructions match the installed version.

## Validation and limits

The Linux fixture suite covers both packages, the CLI, runtime ownership and
policy, merge guards, conductor events and Go race tests. Pagination was also
checked against the live GitHub API with GitHub CLI 2.46.0 and multiple pages.

A cold Codex trial exposed the pagination defect. After temporarily upgrading
its GitHub CLI, that trial completed planning, TDD engineering, independent review
and guarded merge. This release fixes the original compatibility failure; the
entire live model trial was not repeated for this patch. Claude live delivery,
parallel live delivery and interruption recovery were not revalidated in that
trial.

Linux is supported; macOS/native Windows are not. Claude quota-aware dispatch
requires a separate usage collector. Model availability depends on the account.
See [requirements](https://github.com/josemodena/squad/blob/v0.4.2/docs/getting-started/requirements.md) and
[limitations](https://github.com/josemodena/squad/blob/v0.4.2/docs/reference/limitations.md) before enabling unattended recovery.
