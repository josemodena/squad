# Squad 0.4.4 — direct Project Manager meetings in Zellij

Ask the Administrator for planning or a retrospective. Squad opens a new Zellij
tab with an interactive Project Manager session, using the project's configured
model and effort. Talk directly to it while agreed execution continues separately.
The Administrator does not relay the conversation.

- Both Codex and Claude Code launchers; default meeting effort is `high`.
- Project/harness isolation, duplicate-tab focus and durable conversation notes.
- Native session UUID capture through SessionStart hooks where supplied, with
  exact-ID resume. Without an ID, recovery uses notes in a fresh conversation.
- Explicit reconciliation for ambiguous launches and idempotent completion events.
- Meeting hooks preserve tab identity and avoid publishing Administrator handovers
  or prompting commits of unrelated implementation files.

Update the plugin and any checkout-backed CLI, then start a fresh Administrator
session. Run inside Zellij or configure `meeting_zellij_session` to an existing
session. Zellij must support initial commands with `action new-tab`; tested on
0.44.3. See the [meeting guide](https://github.com/josemodena/squad/blob/v0.4.4/docs/guides/meetings.md)
for commands and recovery.

Completion is delivered through durable Squad runtime events at coordination or
recovery boundaries; it does not forcibly interrupt a busy Administrator or resume
paused execution. A proposed plan still requires user agreement.

Validation includes unit fixtures and an isolated real-Zellij test exercising both
plugin entry points and all meeting-aware hooks with stub model CLIs. This checks
interactive terminals, project/model arguments, session binding and duplicate focus
without spending subscription allowance. Live model conversations were not run.
