# Roadmap

Priorities are proposals for community discussion, not release-date commitments.

- Validate native notification, interruption and recovery behaviour across more
  harness versions and account configurations, with reproducible redacted evidence.
- Provide a supported Claude usage-collector integration and per-project recovery
  instances, replacing the single-project terminal adapter limitation.
- Harden recovery path quoting and installation diagnostics.
- Improve measurement of coordination delay and reviewed delivery output without
  claiming exact per-agent attribution of shared subscription consumption.
- Evaluate macOS and WSL2 support with automated coverage before advertising it.
- Reduce remaining duplication between Bash adapters where semantics truly match.

The first priority is reliable, observable coordination. Additional roles or
features should demonstrate a delivery benefit rather than increasing process for
its own sake. Propose changes through the feature-request form.
