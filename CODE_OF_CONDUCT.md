# Code of Conduct

Help make this project useful and welcoming to people with different backgrounds
and levels of experience.

Be respectful, explain technical disagreements with evidence, accept corrections,
and give feedback about the work rather than the person. Credit contributions
fairly and protect other people's private information.

Harassment, threats, discriminatory abuse, sexualised conduct, deliberate
intimidation and publishing private information without permission are not
acceptable in project spaces or when representing this project.

Maintainers may edit or remove content, close disruptive discussions, restrict
participation or block accounts to protect the community. They should explain
moderation decisions where doing so does not expose someone to further harm.
Apply these expectations consistently, including to maintainers.

For ordinary problems, contact the repository maintainers through GitHub. For
sensitive reports, use GitHub's private reporting channel linked in SECURITY.md
and identify the report as a conduct concern. Do not post private details in a
public issue. If no private channel is available, open an issue asking for a
private contact method without including the sensitive material.
